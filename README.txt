CATATAN METRIK
- Response Rate = Lead / Jumlah materi promo disebar
- Conversion = Closing / Lead
- CPL = Biaya Promo / Lead
- CPA = Biaya Promo / Closing
- ROAS = Omzet Promo / Biaya Promo
- HPP disimpan untuk pengembangan analisis laba berikutnya.
